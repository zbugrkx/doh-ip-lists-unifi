# DoH IP lists for UniFi

The lists are derived from [dibdot/DoH-IP-blocklists](https://github.com/dibdot/DoH-IP-blocklists), (c) dibdot, licensed GPL-3.0. Modification: comments and invalid lines are removed, entries are sorted; the IP data itself is unchanged.

Plain-text copies of those lists: one IP or CIDR per line, and no comments, for UniFi gateways that reject comments.

Refreshed daily at 05:17 UTC by GitHub Actions. A run that yields fewer than 500 entries per list fails and keeps the previous files.

- IPv4: https://raw.githubusercontent.com/zbugrkx/doh-ip-lists-unifi/main/doh-ipv4.txt
- IPv6: https://raw.githubusercontent.com/zbugrkx/doh-ip-lists-unifi/main/doh-ipv6.txt
